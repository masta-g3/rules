01 / PurposeFor maintainers and contributors

Shared instructions for AI coding work.

This repo defines how agents plan, build, review, and record changes in your projects.

Example task in your project

"Add dark mode. Plan it before changing code."

The app lives in your project, not here.

  1. 01
    A plan you can inspect

    Scope and checks before implementation.

  2. 02
    A change you can review

    Code and verification against the plan.

  3. 03
    A record you can resume

    Task state and plans in agent-work/.

Skills supply instructions. Helpers and extensions support them.Next: workflow →

02 / Workflow

Each step stops for you.

For tracked work, follow this sequence. A handoff label names the next step; it does not run it.

  1. next-feature1

    Choose a ticket

    READY FOR PLAN

  2. plan-md2

    Define scope and checks

    READY FOR EXECUTE

  3. execute3

    Implement and verify

    READY FOR REVIEW

  4. review4

    Check the implementation

    READY FOR REFLECT

  5. reflect5

    Edit lasting guidance if needed

    READY FOR COMMIT

  6. commit6

    Commit and close out

    WORKFLOW COMPLETE

Default: user-gated. Chaining or orchestration requires an explicit request.Next: files →

04 / Use it

Sync once. Invoke each step.

  1. 01
    ./sync-prompts.sh

    Run from this repo to deploy to Claude, Cursor, and Pi.

  2. 02
    In your project, ask:
    Use plan-md to plan dark mode.

    Start with a concrete task. Use next-feature when choosing from a backlog.

  3. 03
    Read the result.
    Request the next step.

    For example, ask to use execute after approving the plan.
