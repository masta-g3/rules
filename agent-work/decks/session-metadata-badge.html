State variants: ◇ meta active · ◆ meta generating · ◇! meta unavailable · ◇× meta authentication failure · ◇· meta disabled.

Recommendation

Keep the healthy state neutral

The badge stays dim when the extension works. Amber means the metadata model timed out or is unsupported. Red is reserved for authentication failure. The glyph changes with the color, so the state remains clear in a monochrome terminal.

◇ meta
Extension active
◆ meta
Metadata request running
◇! meta
Request failed or timed out
◇× meta
Authentication failed
◇· meta
Extension disabled
