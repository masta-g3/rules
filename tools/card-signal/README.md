# Card signal study

Run from Rules with Node 22.19+ and an installed, authenticated Pi. Replay one file with `node --experimental-strip-types tools/card-signal/cli.ts replay <session.jsonl> --out /tmp/card-replay`; add `--judge --sample 120` to score moments with `openai/gpt-6.1-sol`. Real inputs under `~/.pi/agent/sessions` require temporary output automatically; use `--real` for copied real inputs. Raw real timelines, field values and verdict reasons must never enter Git. Timeline rows encode constant-state intervals, including every second, without repeating idle rows. `metrics.json` also reports per-episode and aggregate `execute_cadence`: task/phase tick batches, update intervals, final-plan completeness, plan-call share and the last non-plan-change-to-tick lag. Cadence uses published task counts; unknown completion stays unknown, and shell attribution needs a matching published change. To reproduce the study, create a fresh `/tmp/card-mocks` directory path, then run `tools/card-signal/run-mocks.sh --out /tmp/card-mocks --question-extension "$HOME/.pi/agent/npm/node_modules/@juicesharp/rpiv-ask-user-question/index.ts" --claude-extension "$HOME/.pi/agent/git/github.com/earendil-works/pi-claude-code/src/index.ts"`. Adjust installed extension paths if needed. The runner uses throwaway Git projects, persistent RPC, a 20-second question wait and an aborted tool. It runs 13 agreed model/scenario combinations, skips completed manifests, and stops on a failed run without spending retry budget. Then run `node --experimental-strip-types tools/card-signal/study.ts --mocks /tmp/card-mocks --out /tmp/card-real --mock-out <hub>/agent-work/tickets/card-signal-001/mock`. This selects 25 recent eligible non-subagent sessions and scores 120 seeded, session-capped moments across both groups. Cached verdicts use a hash of the model, prompt and complete sample; unchanged samples make no model calls. This study retains a 669 KB mock-only replay corpus at `<hub>/agent-work/tickets/card-signal-001/mock/inputs/`. Run `cli.ts replay <hub>/agent-work/tickets/card-signal-001/mock/inputs/*/session.jsonl --out <hub>/agent-work/tickets/card-signal-001/mock --judge --sample 45` through the same Node command to reproduce its mock results without new model calls. Keep useful mock artifacts only, and remove raw mock directories after extraction if they exceed 2 MB. Run tests with `node --experimental-strip-types --test tests/card_signal*.test.mjs`.
